# The committed data has five unique items without a name and 18 client strings nothing reads

**Status:** open
**Area:** data
**Origin:** [renderer/public/data/en/items.ndjson](../../../../renderer/public/data/en/items.ndjson)
**Verified:** 2026-10-25

Three data tool changes of 2026-10-25 change the generated data, and this copy of the tool cannot
regenerate the committed data without dropping other lines
([052](052-dataparser-older-than-committed-data.md)). In each of the nine languages:

- `items.ndjson` has five unique records without `name` and `refName`: three on `Ring` (Safrin's
  Resolve, Eshtera's Path and Zaida's Longevity), one on `Shaman Mantle` and one on
  `Runemastered Shaman Mantle` (both Reverie). `make-index-files.mjs` indexes them under the key
  `UNIQUE::undefined`. `name_uniques()` in `dataParser/src/services/unique_names.py` now names them
  from the game's `Words` table.
- `items.ndjson` gives four unique records the game's internal name as `refName`, a name that the
  trade site's item list does not have: `Brynabas` for Byrnabas, `Splinter of Loratta` for
  Splinter of Lorrata on two bases, and `The Immortan` for The Road Warrior. The price check sends
  `refName` to the trade site when it searches in English, and looks up the price file by it. The
  tool now writes the trade site's name.
- `client_strings.js` has 18 keys that nothing reads and that `TranslationDict` no longer declares:
  `SHAPER_MODS`, `ELDER_MODS`, `CRUSADER_MODS`, `HUNTER_MODS`, `REDEEMER_MODS`, `WARLORD_MODS`,
  `REQUIREMENTS`, the eight `CHAT_*` regular expressions, `WAYSTONE_TIER`, `FRACTURED_ITEM` and
  `UNIQUE_MODIFIER`. An extra key in the default export does no harm, and the tool no longer
  writes them.

`RUNIC_WARD` needs no update: the committed text of each language is what the tool now writes.

A regeneration would change 81 lines of `items.ndjson` (9 per language) and remove 270 lines of
`client_strings.js` (18 keys and 12 comment lines per language).

Done looks like: the data regenerated by a tool that includes these changes, with these lines
changed and no other change to them. Then `renderer/src/assets/make-index-files.mjs` fails on an
item without `refName`, with a test, which the committed data would fail today.

## History

- 2026-10-25: Found while comparing a build of the data tool with the committed data, after the
  tool started naming uniques by the name the game shows and stopped writing unread client strings.
